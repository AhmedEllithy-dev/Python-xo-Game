🎮 Python XO Game

A simple Tic-Tac-Toe (XO) game built using Python.

📌 About The Project

This project is a Python implementation of the classic XO game. It is organized into multiple files to make the code easier to understand and manage.

🛠️ Technologies Used

- Python
- Object-Oriented Programming (OOP)

📂 Project Files

- "board.py"
- "game.py"
- "main.py"
- "player.py"

🎯 Project Goal

To practice Python programming, problem-solving, and OOP concepts.
